# 基准线对比

基准线功能用于展示**计划日期**与**实际日期**的对比，帮助直观发现延期情况。

## 什么是基准线

基准线（Baseline）是项目排期时设定的"计划日期"。随着项目推进，实际执行日期可能偏离计划。通过对比可以：

- 直观发现哪些任务延期了
- 评估项目整体偏差
- 为后续排期提供参考

## 启用基准线

### 1. 任务设置基准线字段

```ts
const tasks: GanttTask[] = [
  {
    id: 't1',
    name: '需求分析',
    // 实际日期
    startDate: '2025-01-03',     // 比计划晚2天开始
    endDate: '2025-01-08',       // 比计划晚3天结束
    progress: 80,
    // 基准线（计划日期）
    baselineStart: '2025-01-01',
    baselineEnd: '2025-01-05',
  },
  {
    id: 't2',
    name: '方案设计',
    startDate: '2025-01-09',
    endDate: '2025-01-15',
    progress: 50,
    baselineStart: '2025-01-06',
    baselineEnd: '2025-01-12',   // 比计划晚了
  },
]
```

### 2. 开启 showBaseline

```vue
<GanttChart :data="tasks" :show-baseline="true" />
```

## 渲染效果

```
实际条形（彩色）：     ━━━━━━━━━━━━
基准线（灰色空心）：  ━ ─ ─ ─ ─ ─ ─ ─ ━
                     ↑              ↑
                  计划开始        计划结束

如果实际结束 > 基准结束 → 条形标红（overdue）
```

### 具体效果

| 元素 | 效果 |
|---|---|
| 实际条形 | 彩色实条，按正常样式渲染 |
| 基准线 | 灰色空心条（普通任务）或空心菱形（里程碑） |
| 延期标记 | 当实际结束日期 > 基准结束日期时，条形自动标红 |

## 里程碑基准线

里程碑也可以有基准线：

```ts
{
  id: 'm1',
  name: '版本发布',
  startDate: '2025-01-20',       // 实际发布日期
  milestone: true,
  baselineStart: '2025-01-15',   // 原计划 1/15 发布
}
```

渲染效果：
- 实心菱形：实际发布日期（1/20）
- 空心菱形：计划发布日期（1/15）
- 因为延期了，实心菱形标红

## 汇总任务基准线

汇总任务（有子任务的父任务）的基准线自动取子任务的极值：

```ts
{
  id: 'phase1',
  name: '第一阶段',
  // 不需要设置 baselineStart/baselineEnd
  // 会自动取子任务的基准线极值
  children: [
    {
      id: 't1',
      name: '任务A',
      startDate: '2025-01-03',
      endDate: '2025-01-07',
      baselineStart: '2025-01-01',
      baselineEnd: '2025-01-05',
    },
    {
      id: 't2',
      name: '任务B',
      startDate: '2025-01-08',
      endDate: '2025-01-15',
      baselineStart: '2025-01-06',
      baselineEnd: '2025-01-12',
    },
  ],
}
// phase1 的基准线自动为：01-01 ~ 01-12
```

## 预期进度对比

除了日期对比，还可以对比进度：

```ts
{
  id: 't1',
  name: '开发任务',
  startDate: '2025-01-01',
  endDate: '2025-01-10',
  progress: 30,           // 实际进度 30%
  expectedProgress: 50,   // 预期进度 50%（按时间应该到50%了）
}
```

```vue
<GanttChart :data="tasks" :show-expected-progress="true" />
```

开启后条形上会显示一条竖线标记预期进度位置。如果实际进度 < 预期进度，说明任务落后了。

## 实战：项目复盘

### 场景

项目结束后复盘，对比计划与实际执行情况：

```ts
const tasks: GanttTask[] = [
  {
    id: 'req',
    name: '需求分析',
    startDate: '2025-01-01',
    endDate: '2025-01-06',    // 实际多花了1天
    progress: 100,
    baselineStart: '2025-01-01',
    baselineEnd: '2025-01-05',
  },
  {
    id: 'design',
    name: '方案设计',
    startDate: '2025-01-07',  // 因需求延期而推迟
    endDate: '2025-01-15',    // 实际多花了3天
    progress: 100,
    baselineStart: '2025-01-06',
    baselineEnd: '2025-01-12',
  },
  {
    id: 'dev',
    name: '开发实现',
    startDate: '2025-01-16',
    endDate: '2025-01-28',    // 延期5天
    progress: 100,
    baselineStart: '2025-01-13',
    baselineEnd: '2025-01-23',
  },
]
```

```vue
<GanttChart :data="tasks" :show-baseline="true" />
```

### 效果

- 需求分析：轻微延期（1天），条形略微标红
- 方案设计：延期3天，条形标红
- 开发实现：延期5天，条形明显标红
- 所有基准线灰色空心条清晰可见，对比一目了然

## 适用场景

| 场景 | 说明 |
|---|---|
| **项目回顾** | 对比计划与实际，分析延期原因 |
| **进度监控** | 实时发现偏离计划的任务 |
| **汇报展示** | 直观展示项目执行情况 |
| **风险预警** | 配合关键路径，发现关键任务延期 |
| **持续改进** | 积累历史基准数据，优化后续排期 |

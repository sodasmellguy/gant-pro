# 国际化

gantt-pro 内置中英文，并支持完全自定义标签。

## 内置语言

```ts
type GanttLocale = 'zh-CN' | 'en-US'
```

### 中文（默认）

```vue
<GanttChart :data="tasks" locale="zh-CN" />
```

### 英文

```vue
<GanttChart :data="tasks" locale="en-US" />
```

## 部分覆盖

通过 `labels` 覆盖单个标签：

```ts
const labels = {
  taskName: 'Task',
  searchPlaceholder: 'Search...',
}
```

```vue
<GanttChart :data="tasks" locale="en-US" :labels="labels" />
```

## 完整标签列表

| 标签 key | 中文默认值 | 英文默认值 |
|---|---|---|
| `taskName` | 任务名称 | Task Name |
| `startDate` | 开始日期 | Start Date |
| `endDate` | 结束日期 | End Date |
| `owner` | 负责人 | Owner |
| `progress` | 进度 | Progress |
| `noData` | 暂无数据 | No Data |
| `today` | 今天 | Today |
| `weekend` | 周末 | Weekend |
| `year` | 年 | (空) |
| `quarter` | Q | Q |
| `month` | 月 | (空) |
| `week` | 周 | W |
| `day` | 日 | (空) |
| `hour` | 时 | h |
| `firstHalf` | 上半年 | H1 |
| `secondHalf` | 下半年 | H2 |
| `deleteTask` | 删除任务 | Delete Task |
| `addLink` | 添加依赖 | Add Dependency |
| `copyDates` | 复制日期 | Copy Dates |
| `snapHere` | 吸附到此位置 | Snap Here |
| `deleteLink` | 删除连线 | Delete Link |
| `changeLinkType` | 修改类型 | Change Type |
| `searchPlaceholder` | 搜索任务… | Search tasks… |

## 其他语言

完全自定义所有标签即可支持任意语言：

```ts
const jaLabels = {
  taskName: 'タスク名',
  startDate: '開始日',
  endDate: '終了日',
  owner: '担当者',
  progress: '進捗',
  noData: 'データなし',
  today: '今日',
  weekend: '週末',
  // ... 其余字段
}
```

```vue
<GanttChart :data="tasks" :labels="jaLabels" />
```

## 从 BUILTIN_LABELS 获取

```ts
import { BUILTIN_LABELS } from '@gantt-pro/core'

const zhLabels = BUILTIN_LABELS['zh-CN']
const enLabels = BUILTIN_LABELS['en-US']
```

# 项目介绍

`gantt-pro` 是一个**零第三方运行时依赖**的跨框架甘特图组件库，专为个人开发者和团队打造。

## 它解决什么问题

你在做项目管理系统、生产排程、研发看板时，需要一个功能完整、交互丰富的甘特图组件。市面上的方案要么依赖太重（dhtmlx 500KB+），要么功能太少（frappe-gantt 无关键路径、无撤销），要么只支持一个框架。

`gantt-pro` 的目标：**一个 npm 包，Vue 和 React 都能用，功能对标企业级，体积控制在 45KB 以内。**

## 核心特性一览

### 零依赖

不引入 `dayjs`、`lodash`、`sortablejs` 或任何 UI 框架。所有日期运算、拖拽排序、状态管理全部自实现：

- 日期工具：`toDate`、`addDays`、`diffDays`、`startOfWeek` 等 20+ 函数
- 拖拽排序：自实现 PointerEvent 方案，不依赖 sortablejs
- 状态管理：自实现 Signal/Computed 响应式原语，不依赖 Vue/React 的响应式

### 跨框架架构

```
┌──────────────────────────────────────────┐
│           你的应用 (Vue / React)           │
├──────────────┬───────────────────────────┤
│ @gantt-pro/  │ @gantt-pro/               │
│    vue       │    react                  │  ← 适配层（薄）
│ (GanttChart) │ (GanttChart)              │
├──────────────┴───────────────────────────┤
│          @gantt-pro/core                  │  ← 核心层（厚）
│  GanttEngine / 几何 / 日期 / CPM / 导出    │
└──────────────────────────────────────────┘
```

| 包 | 说明 | 体积 (min+gzip) |
|---|---|---|
| `@gantt-pro/core` | 框架无关核心层 | ~28KB |
| `@gantt-pro/vue` | Vue 3 适配层 | ~8KB |
| `@gantt-pro/react` | React 18+ 适配层 | ~9KB |

### 企业级功能

#### 关键路径分析 (CPM)

内置 Critical Path Method 算法：

1. 拓扑排序（Kahn 算法）检测依赖环
2. 正向遍历计算每个任务的最早开始/结束时间
3. 逆向遍历计算最晚开始/结束时间
4. 浮时 = 最晚开始 - 最早开始，浮时 ≤ 0 即为关键任务

开启后关键任务和连线自动标红。

#### 依赖顺推

拖拽改变任务时间后，后续依赖任务自动顺推。支持四种依赖类型：

- `fs`（Finish-Start）：前置完成后后续才能开始
- `ss`（Start-Start）：前置开始后后续才能开始
- `ff`（Finish-Finish）：前置完成后后续才能完成
- `sf`（Start-Finish）：前置开始后后续才能完成

多条前驱取满足全部约束的最大平移量，迭代传播至稳定。检测到环则跳过。

#### 基准线对比

每个任务可设置 `baselineStart` / `baselineEnd`（计划日期），与实际日期对比展示。延期任务自动标红。

#### 撤销/重做

所有操作（拖拽移动、端点缩放、进度拖拽、行内编辑、行排序、删除任务）都记录到历史栈。支持 `undo()` / `redo()` 方法。

#### 虚拟滚动

行虚拟化：只渲染可视区内的 20-30 行，滚动时动态替换 DOM。
列虚拟化：时间列超过 180 列时自动启用。

无论 500 还是 5000 个任务，DOM 节点数恒定，60fps 流畅。

#### 多图联动

`GanttSyncHub` 同步多个甘特图实例的滚动、缩放、选择、展开状态。

#### 导出

- **PNG** — SVG foreignObject + Canvas 方案，2x 分辨率，CSS 变量自动内联
- **CSV** — 标准 CSV 格式，含 ID/名称/日期/进度/负责人/里程碑
- **JSON** — 完整任务树 JSON 序列化

#### 工作日历

`createWorkCalendar()` 创建工作日历实例，支持自定义周末、节假日、调休补班。计算有效工期时自动排除非工作日。

### 丰富的交互

| 交互 | 说明 |
|---|---|
| 拖拽移动 | 拖拽任务条改变时间 |
| 左右端缩放 | 拖拽条形两端改变持续时间 |
| 拖拽进度 | 拖拽进度圆点改变完成度 |
| 行拖拽排序 | 拖拽行改变任务顺序和层级 |
| 行内编辑 | 双击单元格直接修改 |
| 右键菜单 | 删除任务/添加依赖/复制日期/吸附位置 |
| 搜索高亮 | 关键词匹配任务名称高亮 |
| 吸附对齐 | 拖拽时按步长吸附日期 |
| Ctrl+滚轮缩放 | 逐级切换刻度，鼠标位置为锚点 |
| 触摸双指缩放 | 移动端 pinch zoom |
| 视口外指示器 | 任务不在可视区时边缘显示箭头 |

## 技术栈

- **TypeScript** — 完整类型定义，IDE 智能提示
- **Vue 3** / **React 18+** — 适配层
- **Vite** — 构建工具
- **Vitest** — 测试框架
- **CSS 变量** — 主题系统，无需 CSS-in-JS

## 浏览器兼容

- Chrome / Edge 88+
- Firefox 87+
- Safari 14+

::: tip
不支持 IE 11。使用了 CSS 变量、PointerEvent、ResizeObserver 等现代 API。
